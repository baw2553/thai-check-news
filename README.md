# Thai Check News — permanent archive and fast search

ภาพรวมการทำงานทั้งเว็บ ส่วนขยาย คลังข่าว และข้อจำกัดของแบบจำลอง: `PLATFORM_WORKFLOW.md`

ต้นแบบประกอบด้วยเว็บตรวจข่าวและ Chrome/Edge Extension สำหรับส่งข้อความที่ผู้ใช้เลือกและ URL ของหน้าข่าวไปค้นหาเหตุการณ์เดียวกัน แม้แต่ละแหล่งจะใช้พาดหัวต่างกัน

## เทียบวิธีเล่าของบทความต้นทาง (รุ่นทดลอง)

คลิกขวาบนหน้าบทความหรือคลุมข้อความแล้วคลิกขวา → **ตรวจข่าวนี้กับ Thai Check News** ส่วนขยายส่ง URL หน้าเว็บผ่าน `sourceUrl` มายังเว็บ เว็บดึง HTML สาธารณะจากโดเมนสำนักข่าวที่อนุญาตเท่านั้น ไม่ได้มี API บทความเต็มของทุกสำนัก จากนั้นค้นเรื่องเดียวกันในคลัง และลองอ่านเนื้อหาจาก URL ของสำนักอิสระเพื่อเทียบประเด็น

- ไม่พบข่าวเรื่องเดียวกันในคลัง: แจ้งว่าเทียบความถูกต้องไม่ได้
- เปิดต้นทางไม่ได้ หรือหน้าเว็บไม่มีเนื้อหาบทความพอ: แจ้งสาเหตุ ไม่เดาจากพาดหัวหรือ meta description
- อ่านต้นทางได้ แต่ยังอ่านแหล่งอิสระอื่นไม่ได้: แจ้งว่าหลักฐานเทียบไม่พอ
- อ่านได้ทั้งสองฝั่ง: แสดงข้อความบางส่วนที่มีคำสำคัญสอดคล้องกัน รายละเอียดเพิ่มที่ยังไม่พบในแหล่งเทียบ และลิงก์หลักฐาน แยกสัญญาณถ้อยคำเร้าอารมณ์ออกจากข้อเท็จจริง ไม่อ้างว่าเป็นการตัดสินเจตนาหรือข่าวเท็จ

นี่เป็นการเทียบคำสำคัญแบบระมัดระวัง **ยังไม่ใช่โมเดล AI ที่ฝึกจากตัวอย่างข่าวใส่สีตีไข่** และคำว่า “ไม่พบในแหล่งเทียบ” ไม่ได้แปลว่าข้อมูลผิด ดูผลตรวจแหล่งเว็บปัจจุบันใน `SOURCE_ACCESS_AUDIT.md`

## เกณฑ์สถานะ

- ยืนยันจากหลายแหล่ง: พบอย่างน้อย 3 แหล่งอิสระ หรือพบแหล่งหลัก/ต้นทางร่วมกับข่าวอิสระอีกอย่างน้อย 1 แหล่ง โดยองค์ประกอบของเหตุการณ์สอดคล้องกัน
- พบข่าวใกล้เคียง — อ่านต่อ: พบอย่างน้อย 2 สำนัก แต่รายละเอียดอาจไม่ตรงทั้งหมด
- กำลังพิจารณา — หลักฐานยังไม่พอ: ยังไม่พบข้อมูลหรือความแพร่หลายมากพอ สถานะนี้ไม่ใช่การตัดสินว่าเป็นข่าวเท็จ

## ติดตั้ง Extension แบบทดสอบ

1. เปิด `chrome://extensions` หรือ `edge://extensions`
2. เปิด Developer mode
3. เลือก Load unpacked
4. เลือกโฟลเดอร์ `extension` ในโครงการนี้ (เลือกทั้งโฟลเดอร์ที่มี `manifest.json`) หากติดตั้งเวอร์ชันเดิมอยู่ ให้กด Reload ในหน้าส่วนขยายหลังแทนไฟล์

ระบบดึงข่าวจาก Google News RSS, Bing News RSS, Thai PBS และ RSS สาธารณะ หน้าข่าวหลักตรวจข้อมูลใหม่ทุก 30 นาทีเมื่อมีผู้เปิดเว็บ ส่วนข่าวที่เพิ่งรับเข้ามาหรือมีเนื้อหาปรับปรุงจริงจะอยู่หน้าหลัก 24 ชั่วโมงนับจากครั้งนั้น การดึงข่าวเดิมซ้ำไม่ต่ออายุ โดยข่าวเก่ายังค้นได้จากคลังถาวร หากต้องการให้เก็บข่าวต่อเนื่องในช่วงไม่มีผู้เปิดเว็บ ต้องมีงานตามเวลาที่เรียกตัวอัปเดตด้วย

งานตามเวลาเรียก `POST /api/refresh` ทุก 30 นาทีหลังเผยแพร่ โดยใส่ `x-tcn-refresh-token` ที่ได้จากช่อง `siwc_bypass_bearer_token` ของ Site เดียวกันผ่าน `get_site` ในแต่ละรอบ ค่านี้ต้องตรงกับ Site secret `TCN_REFRESH_TOKEN`; อย่าบันทึกค่าจริงลงไฟล์หรือข้อความกำหนดงาน หลังคำขอสำเร็จตรวจ `GET /api/live` และ `GET /api/archive` ว่าข้อมูลอ่านกลับได้ หากต้นทางล่มให้ลองรอบถัดไปและแจ้งเฉพาะข้อผิดพลาด ไม่สร้างข่าวหรือข้อมูลราคาทดแทน

ข้อมูลทองคำตรวจรอบใหม่เวลา 00:00 น. และผลสลากกินแบ่งรัฐบาลเวลา 12:00 น. ตามเวลาไทย เก็บภาพข้อมูลต่อวันในฐานข้อมูล ถ้าต้นทางยังไม่ประกาศข้อมูลใหม่หรือเชื่อมต่อไม่ได้ จะระบุข้อมูลเก่า/ข้อขัดข้องและลองตรวจซ้ำทุก 30 นาที ไม่สร้างตัวเลขแทนต้นทาง ข่าวสด YouTube ยังคงตรวจทุก 1 นาทีตามเดิม

ฐานข้อมูล D1 เก็บรายการตั้งแต่ 28/09/2026 โดยไม่มีการลบทิ้งตามอายุ คลังค้นย้อนหลังจากวันที่เริ่มต้นได้และแบ่งหน้า 40 รายงาน ไม่จำกัดการค้นทั้งหมดไว้ที่ 220 ข่าวล่าสุดอีกต่อไป เพิ่มข้อมูลจากหน้า archive วันที่ 28 ของ Thai PBS เท่าที่ต้นทางยังเปิดให้เข้าถึง ไม่อ้างว่าเก็บทุกข่าวในอดีตได้ครบ

ค้นหาในคลังก่อน (`phase=archive`) แล้วตรวจต้นทางเพิ่ม (`phase=full`) โดยไม่ดึงฟีดทุกสำนักใหม่ในแต่ละคำค้น จัดเก็บข้อความมาตรฐานและคำสำคัญสำหรับค้น; memoize องค์ประกอบของพาดหัวแทนคำนวณใหม่ในทุกคู่ข่าว ใช้แคชและรวมคำขอที่ซ้ำกัน โดยฐานข้อมูลเป็นแหล่งข้อมูลถาวร ส่วนแคชเป็นเพียงตัวช่วยความเร็ว

สรุปเกณฑ์เดิมไม่ใช่การฝึกโมเดลข่าวจริงขนาดใหญ่: เป็นตัวจำแนกจากตัวอย่างสังเคราะห์ร่วมกับกฎ ยังต้องมีชุดข่าวจริงที่ติดป้ายกำกับและการประเมินก่อนอ้างถึง AI ที่ผ่านการฝึกเพื่อยืนยันข่าว ระบบไม่นับชื่อภาษาไทย/อังกฤษของสำนักเดียวกันเป็นคนละแหล่ง และไม่นำทุกข่าวที่มีคำค้นคล้ายกันมารวมเป็นหลักฐานของเหตุการณ์เดียวกัน

หน้าผลตรวจแสดงข่าวคล้ายกัน ลำดับเวลาเผยแพร่ ข้อความคัดย่อที่มีที่มา และลิงก์ต้นทาง ข้อความคัดย่อที่อ่านได้เก็บในคลังด้วย (ไม่คัดลอกบทความเต็ม) ถ้าค้นเพิ่มขัดข้องจะรักษาผลเดิม ไม่เปลี่ยนเป็นข่าวเท็จหรือหลักฐานศูนย์
